# Water Flow Sketches

This repository contains two interactive web sketches demonstrating water flow effects using **Three.js**, a JavaScript 3D library. Both `index.html` and `waterflow2.html` are standalone files, each presenting a different visual experiment.

## Technologies Used

*   **HTML5:** For structuring the web pages.
*   **CSS3:** For basic styling.
*   **JavaScript:** The core logic for creating and animating the 3D scenes.
*   **Three.js:** A powerful cross-browser JavaScript library and API used to create and display animated 3D computer graphics in a web browser. The sketches leverage Three.js for rendering the river systems, landscapes, and interactive elements.

## How to View

These sketches are designed to be easily deployed and viewed via GitHub Pages.

1.  **Ensure GitHub Pages is enabled** for this repository. Typically, you can do this in your repository settings under "Pages" by selecting the `main` branch (or `gh-pages` branch) as the source.

2.  Once GitHub Pages is set up, you can access the sketches using the following URLs:

    *   **Main Sketch (`index.html`):**
        `https://kai4avaya.github.io/water-flow/`

    *   **Alternate Sketch (`waterflow2.html`):**
        `https://kai4avaya.github.io/water-flow/waterflow2.html`

    These URLs will load the respective HTML files directly in your browser.
